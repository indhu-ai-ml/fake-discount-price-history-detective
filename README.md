# 🕵️ Fake Discount & Price History Detective

## 📌 About the Project

Fake Discount & Price History Detective is a Python-based web application that analyzes product price history and highlights potentially suspicious discounts.

It helps users compare previous prices with the latest prices and understand how much a product's price has decreased.

## 🎯 Features

* View product price records.
* Select individual products.
* Compare oldest and latest prices.
* Calculate percentage price reductions.
* Highlight potentially suspicious price drops.
* Visualize price history using interactive charts.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Streamlit
* SQLite

## ⚙️ How to Run Locally

1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Run the application using `streamlit run app.py`.

## 📊 Project Purpose

This project demonstrates how Python, data analysis, price comparisons, and data visualization can be combined in a simple interactive web application.

**Note:** The application highlights price drops for investigation. A large price decrease alone does not prove that a discount is fake.
